# 暴走族ゲーム 試遊版

**遊ぶ → https://hoshiyama-blip.github.io/bosozoku-play/**

ここは**ビルド出力の置き場所**です。ソースは `nakagomikou/bosozoku-call`（private）にあります。

## 操作（携帯）

| | |
|---|---|
| 画面の左半分 | 動く（押した所が原点の仮想スティック） |
| 画面の右半分 | 見回す |
| 右下 | 乗る／降りる |
| 左下 | 走る（押している間） |
| **右上** | **「気になる」**。長押しで「良い」 |

画面の上に **徒歩/乗車・座標・向き・fps** が出ます。
★**携帯のスクリーンショットを送ってもらうだけで、場所が特定できます。**
